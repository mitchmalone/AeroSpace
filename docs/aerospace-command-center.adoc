== Description

// tag::body[]
{manpurpose}

The command center shows every workspace as a tile that reflects the real layout of the workspace, including workspaces that are not visible.
Every tile is drawn from the tree, the same way `aerospace dump-workspace-tree` reports it.

Gestures:

* Click a workspace to focus it (same as `aerospace workspace <workspace-name>`). The command center closes.
* Drag a window onto the empty area of another workspace to move it there (same as `aerospace move-node-to-workspace`).
* Drag a window onto the edge of another window to insert it before or after that window (same as `aerospace move-node-to-container`).
* Drag a window onto the center of another window to put both windows under a common container (same as `aerospace join-with`).
* Press Escape or click outside of the tiles to close the command center. The focus is restored to where it was.

The command center is a view of the existing tree. Every gesture maps to a command that already exists, and nothing about tiling changes if you never open it.

Colors of the command center can be configured in the `[command-center]` table of the config.
See xref:guide.adoc#command-center[the guide] for details.
